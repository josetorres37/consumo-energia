## 🎯 Objetivo do Sistema
Este projeto foi desenvolvido como parte do programa de iniciação em tecnologia. O objetivo é ajudar usuários a estimarem o consumo de energia elétrica mensal de seus eletrodomésticos e o custo financeiro gerado com base em dados simples de uso diário.

## 🧮 Fórmula Utilizada
O cálculo do consumo mensal em kWh utiliza a seguinte fórmula matemática:
```text
Consumo Mensal = (Potência em Watts * Horas de Uso Diário * 30 dias) / 1000
```

## 🚀 Como Executar o Programa

1. Certifique-se de ter o **Python 3** instalado no seu computador.
2. Abra o terminal na pasta do projeto.
3. Execute o comando abaixo:
   ```bash
   python app.py
   ```
4. Insira os dados solicitados na tela para ver o consumo e o custo estimado.
